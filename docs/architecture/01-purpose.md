## 1. Purpose

AxData Object provides Axpert's metadata-driven transaction behavior as an API-based service that can be incorporated into any client application. It is a headless transaction runtime, not a simple CRUD layer. It must preserve the permissions, validation, calculation, dependency, grid, mapping, PEG workflow, printing, notification, and persistence behavior defined for an Axpert tstruct.

This document defines the agreed product architecture and service boundaries. Detailed contracts and implementation guidance are in `AxData-Technical-Design.md`. Items requiring confirmation are isolated in `AxData-Clarifications.md`.
