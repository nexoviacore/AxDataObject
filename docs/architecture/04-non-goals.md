## 4. Non-goals for the initial implementation

- Rewriting StructDef, Validate, Parser, or the entire existing Axpert transaction engine.
- Porting the Delphi print service to .NET as part of the first AxData release.
- Creating one independently deployed microservice for every API operation.
- Implementing change-event persistence before full-snapshot performance is measured.
- Sharing an ObjectId with unrelated ordinary users.
