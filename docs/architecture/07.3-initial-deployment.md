## 7.3 Initial Deployment

AxData and PEG should initially be implemented as **cleanly separated modules within a single deployable .NET API**.

```text
                 Axi .NET API
                      |
            +---------+---------+
            |                   |
          AxData               PEG
            |                   |
          Redis              Redis
            |                   |
            +---------+---------+
                      |
               Transaction DB
                      |
             Transactional Outbox
                      |
          +-----------+-----------+
          |           |           |
     Persistence    Print    Notification /
       Worker      Worker     Integration
```

This approach keeps the initial deployment simple and avoids unnecessary distributed-service complexity while maintaining clear internal interfaces between AxData and PEG.

Persistence, printing, notifications, and external integrations should be handled through background workers where appropriate.
