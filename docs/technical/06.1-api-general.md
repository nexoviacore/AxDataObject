### 6.1 General

- Base path: `/api/v1`.
- JSON UTF-8 request/response.
- Authenticated tenant and user come from trusted claims/context, not client-supplied ownership fields.
- Object-changing requests include expected object version and an idempotency/request ID where required.
- Every response includes a correlation ID.
- HTTP status communicates transport/system outcome; the body includes structured business/validation errors.

Recommended headers:

```http
Authorization: Bearer <token>
X-Correlation-Id: <client-or-server-generated-id>
If-Match: "<object-version>"
Idempotency-Key: <unique-logical-request-id>
```

`If-Match` may alternatively be represented as `expectedVersion` in JSON for client compatibility, but one approach should be standardized.
