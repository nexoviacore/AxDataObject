### 6.2 Initialize

```http
POST /api/v1/axdata
```

New transaction request:

```json
{
  "transId": "salesorder",
  "key": null
}
```

Existing transaction request:

```json
{
  "transId": "salesorder",
  "key": {
    "field": "recordid",
    "value": "100501"
  }
}
```

Response:

```json
{
  "status": "success",
  "objectId": "01J...",
  "version": 1,
  "transId": "salesorder",
  "recordId": 100501,
  "readOnly": false,
  "expiresAt": "2026-09-01T08:30:00Z",
  "correlationId": "..."
}
```

`POST /api/v1/axdata/init` may be retained as a compatibility alias if desired.
