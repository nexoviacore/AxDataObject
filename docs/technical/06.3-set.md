### 6.3 Set

```http
POST /api/v1/axdata/{objectId}/set
If-Match: "12"
```

Proposed request shape:

```json
{
  "getDeps": true,
  "data": {
    "dc1": {
      "rows": [
        {
          "rowId": "dc1:1",
          "action": "e",
          "fields": {
            "customer": "C001",
            "orderdate": "2026-08-31"
          }
        }
      ]
    },
    "dc2": {
      "rows": [
        {
          "rowId": "tmp:1",
          "action": "n",
          "fields": {
            "item": "ITEM001",
            "quantity": 2
          }
        }
      ]
    }
  }
}
```

Success with dependent changes:

```json
{
  "status": "success",
  "objectId": "01J...",
  "version": 13,
  "changed": [
    {
      "dc": "dc2",
      "rowId": "tmp:1",
      "field": "amount",
      "value": 250.00,
      "source": "dependency"
    }
  ],
  "errors": []
}
```

Validation response:

```json
{
  "status": "validation_error",
  "objectId": "01J...",
  "version": 13,
  "errors": [
    {
      "code": "AXD-VAL-001",
      "message": "Quantity must be greater than zero.",
      "dc": "dc2",
      "rowId": "tmp:1",
      "field": "quantity"
    }
  ]
}
```

Whether valid independent changes remain applied when another field fails is an explicit clarification item.
