### 6.4 Query/Get

Use POST when the field/DC selection is a JSON document:

```http
POST /api/v1/axdata/{objectId}/query
```

```json
{
  "select": [
    { "dc": "dc1", "fields": ["customer", "orderdate"] },
    { "dc": "dc2", "fields": ["*"] }
  ]
}
```

Complete transaction:

```json
{ "select": "*" }
```

Simple complete retrieval may also support:

```http
GET /api/v1/axdata/{objectId}
```

Response nodes must exclude hidden values and attach read-only metadata according to the requester. `PendingApproval=true` is included for a current authorized approver.
