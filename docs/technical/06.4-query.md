### 6.4 Get

Get always uses an explicit POST route and carries ObjectId in its JSON document:

```http
POST /api/v1/axdata/get
```

Selective transaction request:

```json
{
  "objectId": "01J...",
  "select": [
    { "dcId": "dc1", "fields": ["customer", "orderdate"] },
    { "dcId": "dc2", "fields": ["*"] }
  ]
}
```

Omitting `select`, supplying `null`, or supplying `"*"` returns the complete authorized transaction:

```json
{ "objectId": "01J..." }
```

Response nodes must exclude hidden values and attach read-only metadata according to the requester. `PendingApproval=true` is included for a current authorized approver.

Get loads the tenant-scoped DataObject and uses each DC's stored ordered `[name,flags]` metadata to validate selections and project field order. It does not load StructDef, evaluate expressions, refresh fields, or run validation. The authorization adapter receives this DataObject field map and performs a fresh permission lookup. Final field read-only is transaction read-only OR DC-permission read-only OR stored static field read-only OR field-permission read-only. Hidden DCs/fields remain omitted.
